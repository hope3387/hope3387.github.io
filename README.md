
Chim Go Kien Uploader – Privacy Policy

Last updated: 2026-11-03

Chim Go Kien Uploader is a private automation tool used only by the owner of the Chim Go Kien YouTube channels to upload the owner's own videos, thumbnails, captions and comments to YouTube through the YouTube Data API.
Data accessed

The tool accesses only the YouTube channel(s) that the owner explicitly authorizes via Google OAuth, and only to upload and manage the owner's own content.
Data storage and sharing

OAuth tokens are stored only on the owner's own computer inside the automation software. No user data is sold, shared with third parties, or used for advertising. The tool has no other users.
Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
